How it works

Three steps.
Zero network changes.

Maemuki Bridge works alongside your existing VPN. No IT tickets, no firewall exceptions at the customer site.

01
🔌

FSE connects on-site

The field engineer connects their laptop to the customer's local network and verifies they can reach the PLC.

02
🌐

Run Maemuki Bridge

Launch the app, select the target device, set the listen port, and start the proxy — it takes under a minute.

03
⚡

Office engineer connects

The remote expert connects through the VPN to the FSE laptop address as if the PLC were on their own network.

Key benefits

Built for industrial
field realities.

Designed for FSEs who need results fast — not IT projects that take weeks.

No permanent network changes

Works entirely through the FSE laptop. Customer site infrastructure stays untouched.

Transparent TCP forwarding

Modbus, EtherNet/IP, and any TCP-based protocol passes through unchanged.

Built-in connectivity check

Ping and port verification before starting the forward — know it works before the office engineer tries.

Multiple simultaneous devices

Forward several PLCs at once, each on its own port, from the same laptop session.

Simple for FSE staff

Clean UI with Start menu shortcut. No command line, no complex configuration required.

Live message log

See incoming frames in real time — immediately know if packets from the office are arriving.
